# 04 - Step-by-Step Build Plan

This is the exact restart sequence.

## Step 1: Home page only

Goal: open a webpage and understand the project.

Visible things:

```text
Project Summary Table
Files Used Table
Output File Status Table
```

Do not add charts yet.

Done when:

```text
You understand the project without reading code.
```

## Step 2: GPR page

Goal: understand the geopolitical risk data.

Visible things:

```text
Daily GPR chart
Top GPR shock table
Recent GPR data table
```

Done when:

```text
You can explain what GPR means and identify the biggest spikes.
```

## Step 3: Market reaction page

Goal: understand what markets did around GPR shock dates.

Visible things:

```text
Developed versus emerging return chart
Abnormal return event-study chart
Market Reaction Table
```

Done when:

```text
You can explain whether market reaction looks clear, mixed, or weak.
```

## Step 4: Regression page

Goal: understand what the regressions test.

Visible things:

```text
Regression Translation Table
Raw controlled regression expander
Raw date fixed-effects regression expander
Raw quantile regression expander
```

Done when:

```text
You can explain why the project should be careful about claims.
```

## Step 5: Prediction Lab page

Goal: understand the risk-ranking experiment.

Visible things:

```text
Prediction Lab Translation Table
Feature importance chart
Lift table
Raw metrics expander
```

Done when:

```text
You can explain that this is not a trading signal.
```

## Step 6: Data quality page

Goal: understand what might be wrong or incomplete in the data.

Visible things:

```text
Large return flags
Country coverage
Missing file warnings
```

Done when:

```text
You know whether the data looks usable.
```

## Step 7: Dev cockpit

Goal: watch the project build.

Visible things:

```text
Run buttons
Live logs
Progress bar
Output file status
Preview of latest outputs
```

Done when:

```text
You can press a button and see what changed.
```

## Step 8: Monthly benchmark page

Only add this after the daily project is understandable.

Visible things:

```text
Monthly source table
Monthly benchmark result table
Plain-English warning that monthly sample mode is not evidence
```

Done when:

```text
You can explain how monthly differs from daily.
```
