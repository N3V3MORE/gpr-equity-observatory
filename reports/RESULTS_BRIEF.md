# GPR Equity Observatory Results Brief

## Main Takeaway

The current evidence is mixed. The controlled panel regression finds a negative GPR-return association, but the emerging-market interaction is not strong evidence of a reliably larger emerging-market response.

## Key Evidence

| Method | Estimate | p-value |
| --- | ---: | ---: |
| Controlled panel regression | -0.006% | 0.006 |
| Controlled emerging interaction | 0.009% | 0.127 |
| Tail-risk quantile regression | -0.012% | 0.157 |
| Local projection developed | 0.224% | 0.034 |
| Local projection emerging | 0.367% | 0.696 |
| Drawdown classifier | 0.614 | n/a |

## Sample Robustness

Under `Excluding COVID and Russia windows`, the controlled GPR coefficient is -0.007% with p-value 0.022. The emerging interaction is 0.002% with p-value 0.733.

That means the main controlled GPR coefficient is not only a COVID or Russia-Ukraine result. But the emerging-market asymmetry claim remains weak in the current specification.

## How To Explain This

- This is an empirical risk-response project, not a trading system.
- ETF returns are USD returns, so they include currency exposure.
- GPR shocks are not randomized events, so the results are associations.
- The best current conclusion is cautious: GPR is linked to equity risk, but emerging-market asymmetry is not yet a strong finding.
